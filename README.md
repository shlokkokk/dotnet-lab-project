A full-stack student registration and academic management system built with **ASP.NET Core (C#)** and **React**.

---

## Tech Stack

- **Backend**: C# ASP.NET Core 9.0 Web API, ADO.NET
- **Database**: SQLite
- **Frontend**: React, Vite, Vanilla CSS
- **Deployment**: Docker on Render

---

## Features

- **Registration Portal**: Form validation, dynamic custom hobbies, auto age calculation, and password strength meter.
- **User Directory**: Profile cards and spreadsheet data grid with search, role filters, and CSV/SQL export.
- **Student Portal**: Course elective allocation and assignment uploads.
- **Feedback System**: Interactive star ratings and review directory.
- **Backend Explorer**: Live ADO.NET execution logs and source code viewer.

---

## Getting Started

### Backend
```bash
cd DotNetServer
dotnet run
```

### Frontend
```bash
npm install
npm run dev
```
